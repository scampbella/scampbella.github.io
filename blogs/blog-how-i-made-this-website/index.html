How I Made This Website

March 24, 2024 4 min read

When I set out to build this personal website, I knew I wanted something clean and minimal that reflected my style as a developer. I had tinkered with other frameworks before, but nothing felt quite right until I found the perfect combination of modern tools that made development feel effortless.

Choosing the Right Tools

The backbone of this site is built on Tailwind CSS, a utility-first framework that has completely changed how I think about styling. Instead of writing custom CSS for every element, I can compose designs directly in my HTML using intuitive utility classes. This approach reduces the friction between having an idea and seeing it rendered in the browser.

I paired this with Google Fonts and Material Symbols for typography and icons, giving the site a polished, professional look without compromising on performance. The dark mode toggle was a fun addition that taught me a lot about Tailwind's class-based dark mode system and how to manage state with vanilla JavaScript.

Design Philosophy

I wanted the site to feel like a digital resume and portfolio rolled into one. The color scheme uses a calming blue primary with subtle grays for depth, inspired by Material Design 3. Every section tells a different part of my story \u2014 from the computers I use daily, to the music I'm currently obsessed with, to the club I help run at OSU.

The hardest part wasn't the code \u2014 it was deciding what to include. I wanted to be genuine about who I am: a student who loves hardware, writes code, and shares the things that excite me. This site will keep evolving as I do, and I'm excited to see where it goes.
